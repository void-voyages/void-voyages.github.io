Privacy Policy

Last updated: 19 November 2026

live-clipper is a personal desktop tool used only by its owner. It has no other users and no server; everything runs on the owner's own computer.

What data is used

  • TikTok account data of the owner's own account: the access token and the basic profile (open ID, display name) granted via TikTok Login Kit. They are used only to upload draft videos to that account and to show which account is connected.
  • YouTube / Google account data of the owner's own account, accessed through YouTube API Services: an OAuth access and refresh token, and the channel's ID, title and handle (scope youtube.readonly) to show which channel is connected. The scope youtube.upload is used only to upload the owner's finished clips to that channel. No other Google user data (for example email, contacts, watch history or other videos) is read.
  • Public stream content: video, audio and public chat messages of Twitch live streams, processed to detect highlight moments. Chat messages are analysed in aggregate (message rate) and are not stored after processing.

Where data is stored

All data stays on the owner's own computer. The TikTok and YouTube tokens are stored locally in files and are never shared. Recordings are deleted automatically after a short buffer period. Short text excerpts (transcript and chat) are sent to Google Gemini to rate whether a moment is worth clipping.

Sharing

No data is sold or shared with third parties. Data leaves the computer only to upload the finished clip to the owner's own TikTok and YouTube accounts, for the Gemini rating described above, and to send the owner a notification with the clip and its description via the owner's own Telegram bot. Data received from Google APIs is used only to provide these features and is not transferred to anyone else, used for advertising, or used to train AI models; its use complies with the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

live-clipper uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Deletion and revoking access

  • TikTok: revoke access in the TikTok app (Settings → Security → Manage app permissions).
  • Google / YouTube: revoke access at Google security settings → Third-party apps.
  • Deleting the local token files removes all stored account data. Stored tokens are deleted within 7 days of a deletion request by the owner.
