live-clipper

live-clipper is a private desktop tool used by a single creator. It watches public Twitch live streams, detects highlight moments and edits them into short vertical clips with subtitles and a visible source credit.

Finished clips are published only to the creator's own accounts, using the platforms' official APIs:

  • TikTok (@void.vayages): uploaded as drafts via TikTok Login Kit and the Content Posting API. The creator reviews every draft in the TikTok app and decides whether to post it.
  • YouTube (Void Voyages): uploaded as Shorts via the YouTube Data API v3 (YouTube API Services).

The tool is not offered to other users.
